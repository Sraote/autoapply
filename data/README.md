# data/

Everything in this folder except this file is git-ignored. It holds:

| Path | What |
|---|---|
| `private/resume.pdf` | Your master resume (uploaded to applications) |
| `private/resume.json` | Optional JSON Resume (jsonresume.org schema) |
| `private/linkedin/` | Optional LinkedIn data export (zip or extracted folder) |
| `user_profile.json` | Normalized profile built by `autoapply profile build` |
| `answers_learned.yaml` | Answers you chose to save during human-in-the-loop prompts |
| `autoapply.db` | SQLite job tracker |
| `browser-profile/` | Persistent Chromium profile (cookies, ATS logins) |
| `logs/` | Failure screenshots |
